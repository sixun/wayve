# Skiper UI originals

Private source archive for sixun's purchased Skiper UI components.

## Collection status — 2026-09-30

- Live catalog: **106 components** (IDs 1–107 excluding 93).
- Archived: **103 original source files** in `originals/`.
- Not retrieved: **12 (Vercel Liquid simulation), 14 (Ascii Simulation), 36 (Interactive3d Hero)**. Their demo pages failed in the browser, preventing access to the source panel after retry.
- `manifest.json` records each source URL, UTF-8 byte count and SHA-256.

Source files were read from the authenticated Pro **Source Code** panel and preserved without intentional modifications, including upstream comments. This archive is not the complete Skiper website source or a runnable app. Relative imports and demo assets may require additional upstream files. Website-wide ZIP download was not found in the inspected homepage, dashboard, catalog or source panels.

## Official sources

- Catalog: https://skiper-ui.com/components
- Installation / Pro CLI: https://skiper-ui.com/docs/quick-start

Pro CLI uses a purchased license key in `.env.local` and the authenticated registry described in the official guide. Never commit the key. No credentials are included in this repository.

Purchased source retains its upstream license; this repository grants no additional redistribution rights.
